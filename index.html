Radar de Mercado

A personal automated pipeline that collects, classifies, and summarizes publicly available financial market news on a schedule.

How it works

  • collect.py pulls items from Google News RSS on a daily schedule
  • A classification step uses the DeepSeek API to categorize and deduplicate items
  • Results are committed back to the repository as JSON, giving the pipeline persistent history
  • A static dashboard (Chart.js) renders the data, deployed via Cloudflare Pages
  • Summaries go out by email through Resend

Stack

Python · GitHub Actions · DeepSeek API · Resend · Cloudflare Pages · Chart.js

Status

Actively running in production, orchestrated entirely through GitHub Actions.
